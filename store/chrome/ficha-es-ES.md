# Ficha de Chrome Web Store — Español (España)

Para https://chrome.google.com/webstore/devconsole (cuenta de desarrollador: 5 $ una vez). Paquete:
el mismo zip que Edge, `sOCCredentials-extension-chromium-<versión>.zip` (sin `key`: la tienda pone
el id; cuando lo dé, hay que autorizarlo en el puente con la aplicación).

Chrome pide lo mismo que Edge, así que **los textos y las imágenes son los de Edge** y se mantienen en
un solo sitio:

| Campo de Chrome Web Store | De dónde sale |
|---|---|
| Nombre y descripción corta | Del paquete (`_locales/es/messages.json`) |
| Descripción | [../edge/ficha-es-ES.md](../edge/ficha-es-ES.md), bloque «Descripción» |
| Categoría | **Herramientas** (Chrome no tiene «Productividad» como categoría única) |
| Idioma | Español |
| Icono de la tienda 128×128 | `Extension/common/icons/icon128.png` |
| Capturas 1280×800 | `../edge/imagenes/es-ES/01…03-*.png` |
| Mosaico promocional pequeño 440×280 | `../edge/imagenes/es-ES/mosaico-pequeno-440x280.png` |
| Mosaico de marquesina 1400×560 | `../edge/imagenes/es-ES/mosaico-grande-1400x560.png` |
| Sitio web / asistencia | `https://github.com/donki/Credentials` · `…/issues` |
| Pestaña «Prácticas de privacidad» (propósito único, permisos, código remoto, datos, certificaciones) | [../edge/privacidad.md](../edge/privacidad.md): los mismos textos |
| URL de la política de privacidad | `https://github.com/donki/Credentials/blob/master/PRIVACY.md` |
